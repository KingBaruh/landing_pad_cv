# תיאור ניסוי הווידאו

## ניסוי 2 - כניסת המטרה לתמונה והתקרבות מכיוון אלכסוני

**סרטון:** `videos/v2.mp4`

**מה נבדק:** בדיקת רכישת המטרה כאשר המצלמה מתחילה במבט שאינו כולל את הדף במלואו, מפנה את המבט למיטה ומתקרבת אל הדף מהצד. מוקד הבדיקה הוא הזיהוי הראשוני במהלך הכניסה ושינוי הפרספקטיבה.

**מה הצליח:** ה-Pose הראשון התקבל בפריים 69, כ-2.30 שניות מתחילת הסרטון. לאחר האתחול נשמרו מעקב ו-Pose תקינים בכל 119 הפריימים הנותרים שעובדו, ללא איבוד מעקב רשום. בדוגמת הפלט המסגרת נמצאת על דף ה-X ולא על העצמים המסיחים.

**מה נכשל או נשאר מוגבל:** 69 הפריימים הראשונים שעובדו היו ללא Pose, אך בחלק מהקטע הדף כלל אינו נראה במלואו ולכן אין לספור את כולו כהחמצה. תחילת הנראות המלאה לא סומנה פריים-פריים, ולכן לא נמדד כאן זמן זיהוי מדויק מרגע כניסת המטרה.

**בדיקת העצמים המסיחים:** בניסוי הוצבו לצד המטרה דף A4 לבן ללא X ודף מעוגל עם X. הדף הלבן בודק שצורה מלבנית לבדה אינה מספיקה לזיהוי; הדף המעוגל בודק שסימון X לבדו אינו מספיק. בדגימות הפלט שנבדקו, מסגרת הזיהוי הוצמדה לדף המלבני עם X ולא לשני העצמים המסיחים. ממצא זה תומך בזיהוי המשטח הספציפי בתנאי הניסוי; הוא אינו הוכחה לאפס זיהויי שווא בכל הפריימים או בסביבות אחרות.

**נתוני הריצה:** 119 אומדני Pose שעברו את הבדיקות מתוך 188 פריימים שעובדו; 0 איבודי מעקב. תוצאות וגרפים נמצאים ב-`outputs/experiment_v2/`.

הסקירה החזותית מדגמית; אומדנים שעברו את הסף אינם מדידת דיוק פיזית. לא בוצעה הרצה מחדש לצורך מסמך זה.
